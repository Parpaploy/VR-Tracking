# VR Tracker

ระบบติดตามตำแหน่งและสถานะอุปกรณ์ VR ด้วย React, TypeScript และ Firebase
รองรับการสแกน QR, ย้ายอุปกรณ์ระหว่างโกดัง รถ และร้าน, แก้ไขสถานะ และส่งออกรายงาน CSV

## เริ่มต้น

```sh
npm install
npm run dev
```

ใช้การตั้งค่า Firebase ใน `.env` ตามตัวแปรที่อ่านใน `src/lib/firebase.ts`

```sh
npm run build
npm run lint
```

## ข้อมูลและเส้นทาง

- หน้าจัดการ: `/admin/vr-management`
- หน้าสแกน: `/admin/vr`
- URL เดิมเปลี่ยนเส้นทางไปหน้า VR โดยอัตโนมัติ
- อุปกรณ์ใหม่ใช้รหัส `VR-001`, `VR-002`, …
- ยังคงใช้ Firestore collection `gas` และฟิลด์ `gasId` เพื่อรองรับข้อมูล ประวัติ และ QR เดิม โดยไม่ได้ย้ายหรือแก้ไขข้อมูลบนฐานข้อมูลจริง
- `seedVR.js` เป็นสคริปต์สร้างข้อมูลตัวอย่าง 100 เครื่อง ต้องใช้ Firebase Admin credentials และเขียนข้อมูลจริงเมื่อสั่งรัน
- ชื่อลูกค้าใน `customer.csv` และการตั้งค่า Firebase เดิมยังอ้างถึงแหล่งข้อมูลเดิม
